第 1 章

初识 Vue 3

Vue 是一个专注于构建网页用户界面的 JavaScript 框架。这一章不装任何工具， 只用一个 HTML 文件，就把一个“会自己更新”的页面跑起来，顺便弄清 Vue 到底替我们做了什么。

本章目标

  • 说清“渐进式框架”和“数据驱动视图”是什么意思
  • 知道原书的 Vue 2 生态在今天分别被谁替代了
  • 用 <script> 标签引入 Vue 3，用 createApp 创建并挂载应用
  • 认识文本插值 {{ }} 和第一个指令 v-model
  • 理解“响应式”：改数据，页面自己变

为什么又是一个前端框架？

先想一个最普通的需求：页面上有个输入框，下面有一行字，要求“输入框里打什么，下面那行字就显示什么”。 不用任何框架，你得这么写： 

<input id="box">
<p id="out"></p>

<script>
  const box = document.getElementById('box')
  const out = document.getElementById('out')
  // 每次输入，都要自己去找到 <p>，自己改它的内容
  box.addEventListener('input', () => {
    out.textContent = box.value
  })
</script>

两个元素还好。可真实页面上有几百个元素、几十种数据，一个数据变了要同步改好几处 DOM， 漏掉一处就是 bug。前端框架要解决的核心问题就是：让你只管数据，DOM 由框架负责同步。

渐进式框架

Vue 的作者尤雨溪（Evan You）把 Vue 称为渐进式框架（The Progressive Framework）。“渐进”有三层意思：

  • 可以一点点引入：在已有的老项目里，用一个 <script> 标签就能让某一块区域变成 Vue 管理的。
  • 可大可小：从一个小原型，到有路由、状态管理、服务端渲染的大型应用，都是同一套核心。
  • 上手平缓：新手几分钟就能写出东西，熟手又能马上进入高效状态。

MVVM：View、Model 和中间人

Vue 的设计大致遵循 MVVM（Model-View-ViewModel）思想： View 是用户看到的界面，Model 是数据，Vue 扮演中间的 ViewModel， 负责把两者连起来。数据变了，Vue 决定什么时候、用什么方式更新界面；用户在界面上输入，Vue 把变化写回数据。

Vue 的核心能力可以概括为四点：

⚡

响应式数据

数据一变，用到它的界面自动更新；底层有轻量的虚拟 DOM 和编译期优化。

📝

灵活的视图写法

像 HTML 一样的模板（最常用），也可以写 JSX 或纯 JS 渲染函数。

🧩

组件化

把界面拆成可复用、可组合的小块，每块自带模板、逻辑和样式。

📦

官方配套

路由、状态管理、构建工具、开发者工具都有官方或官方推荐的方案。

浏览器兼容性

Vue 2 依赖 Object.defineProperty，因此不支持 IE8。Vue 3 更进一步： 它的响应式系统基于 ES2015 的 Proxy，而 Proxy 无法被“补丁”到旧浏览器上， 所以 Vue 3 不支持任何版本的 IE，只支持现代浏览器（Chrome、Edge、Firefox、Safari 的近几个版本）。 好消息是 IE 本身也已退役，这对今天的项目几乎不构成限制。

全书使用现代 JavaScript（const/let、箭头函数、模板字符串、解构、async/await、ES 模块）。 第 1–3 章直接在浏览器里运行，不需要任何编译；从第 4 章开始引入 Vite。

一分钟上手

Vue 足够灵活，用一个 <script> 标签就能引入。新建一个 index.html，内容如下： 

<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <title>Vue 3 上手</title>
</head>
<body>
  <!-- 一段普通 HTML，稍后交给 Vue 管理 -->
  <div id="root">
    <p>这是 Hello World 吗？</p>
  </div>

  <!-- 引入 Vue 3 的“全局构建版本”：它会在 window 上挂一个 Vue 对象 -->
  <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>

  <script>
    console.log('我们正在使用 Vue，版本号：', Vue.version)
  </script>
</body>
</html>

🔍 进阶：用 ES 模块 + import map 的写法（点击展开）

现代浏览器支持 import map，可以让你在不装任何工具的情况下写 import { createApp } from 'vue'：

<script type="importmap">
  { "imports": { "vue": "https://unpkg.com/vue@3/dist/vue.esm-browser.js" } }
</script>

<div id="root">{{ message }}</div>

<script type="module">

  createApp({
    setup() {

  }).mount('#root')
</script>

注意：浏览器出于安全考虑，不允许在 file:// 协议下加载 ES 模块，所以这种写法必须用本地服务器打开， 比如在文件所在目录运行 npx serve。这也是本教程前几章选择全局版本的原因 —— 双击就能跑。

创建一个应用

现在页面上有了 Vue，但还没有任何“Vue 应用”在运行。我们需要用 createApp 创建一个应用， 再把它挂载（mount）到页面的某个元素上： 

// 从全局 Vue 对象里取出需要的函数
const { createApp, ref } = Vue

const app = createApp({
  // setup() 是组合式 API 的入口：在这里准备数据和函数
  setup() {
    // ref() 创建一个“响应式”的值
    const message = ref('Hello Vue.js!')

    // 返回的东西，模板里都能直接用
    return { message }
  }
})

// 把应用挂载到 id="root" 的元素上
app.mount('#root')
原书 · Vue 2
var app = new Vue({
  el: '#root',
  data () {
    return {
      message: 'Hello Vue.js!'
    }
  }
})
本教程 · Vue 3
const { createApp, ref } = Vue

createApp({
  setup() {
    const message = ref('Hello Vue.js!')
    return { message }
  }
}).mount('#root')

两个关键变化：

  1. 没有 new Vue 了。Vue 2 的 new Vue 会修改一个全局的 Vue 构造器， 所有应用共享配置，容易互相污染。Vue 3 的 createApp 返回一个独立的应用实例，全局配置都挂在它身上。
  2. 没有 el 选项了，统一用 .mount('#root')。（Vue 2 里的 $mount 方法是它的前身。）

选项式 API 与组合式 API

上面用的 setup() + ref() 叫组合式 API（Composition API），是 Vue 3 引入的新写法。 原书用的 data / methods / computed 写法叫选项式 API（Options API），它在 Vue 3 里依然完全可用： 

Vue.createApp({
  data() {
    return { message: 'Hello Vue.js!' }
  }
}).mount('#root')
★ 本教程的选择

本教程以组合式 API为主，因为它是 Vue 官方文档、新版生态（Pinia、VueUse、Nuxt）的默认写法， 逻辑复用也更自然（第 5 章会用它取代原书的 mixins）。遇到书中原有的选项式写法，我们会用左右对照的方式给出 Vue 3 版本， 两种你都能看懂。

模板让 DOM 动起来

Vue 有好几种描述视图的方式，最简单的是模板（template）：它看起来几乎就是 HTML， 只是多了一些特殊语法，让 DOM 能随数据自动更新。

文本插值

第一个模板语法是文本插值：用两对花括号 {{ }} 包住一个 JavaScript 表达式， Vue 处理模板时会把它替换成表达式的结果。把 <div id="root"> 改成： 

<div id="root">
  <p>{{ message }}</p>
</div>

页面上会显示 Hello Vue.js!。看起来平平无奇，但 Vue 已经把这段 DOM 和数据“接上线”了。 打开控制台，试试修改数据： 

// mount() 的返回值是根组件实例，先在代码里把它存下来：
// const vm = app.mount('#root')
vm.message = '太棒了！'

页面上的文字立刻变了。这叫数据绑定（data binding）：数据一变，Vue 自动更新 DOM，你一行 DOM 代码都不用写。

ⓘ 花括号里能写什么

任何单个表达式都行：{{ count + 1 }}、{{ ok ? '是' : '否' }}、 {{ message.split('').reverse().join('') }}。但不能写语句，比如 {{ if (ok) {...} }} 或 {{ let a = 1 }}。

ref：响应式的“盒子”

在 setup() 里，普通变量是不会触发界面更新的。必须用 ref() 把值包成一个响应式引用。 你可以把 ref 想象成一个带“报警器”的盒子：值放在 .value 里，谁读了它、谁改了它，Vue 都知道。

⚠ 新手最常见的错误：忘了 .value

在 JavaScript 里，message 是那个盒子，message.value 才是里面的字符串。 写成 message = 'Hi' 会直接把盒子扔掉，界面不会有任何反应。模板里则不用写 .value，Vue 会自动“拆箱”。

🔍 深入：Vue 2 和 Vue 3 的响应式有什么不同（点击展开）

Vue 2 用 Object.defineProperty 把对象的每个属性改造成 getter/setter。它的缺点是只能拦截已经存在的属性： 给对象新增属性、用下标给数组赋值（arr[0] = x）都检测不到，必须用 Vue.set 这种补救 API。

Vue 3 改用 Proxy：它代理的是整个对象，任何读、写、新增、删除操作都能拦截。 所以 Vue 3 里不再需要 Vue.set / this.$set，这些“响应式陷阱”基本消失了。 代价就是放弃了 IE 支持。

用指令添加交互

现在给页面加一点交互：一个输入框，让用户修改显示的消息。在模板里，这要靠一种叫指令（directive）的特殊属性。

ⓘ 指令的命名规则

Vue 的所有指令都以 v- 开头，单词之间用短横线连接（kebab-case），例如 v-model、v-on。 因为 HTML 属性名不区分大小写，v-Model 和 v-model 在浏览器眼里是一回事。

我们需要的指令是 v-model，它把 <input> 的值和数据双向绑定： 

<div id="root">
  <p>{{ message }}</p>
  <!-- 新增：输入框，和 message 双向绑定 -->
  <input v-model="message">
</div>

现在在输入框里打字，上面的文字会实时跟着变，DevTools 里的 message 也同步变化。来亲手试一下：

▶ 在线演示 · 这就是上面那几行代码

{{ message }}

字符数：{{ message.length }}　·　倒过来：{{ message.split('').reverse().join('') }}

Vue 内置了很多指令（v-if、v-for、v-on、v-bind……），你甚至可以自己写指令。别急，下一章会一个个用到。

完整代码

<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <title>Vue 3 上手</title>
</head>
<body>
  <div id="root">
    <p>{{ message }}</p>
    <input v-model="message">
  </div>

  <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
  <script>
    const { createApp, ref } = Vue

    const app = createApp({
      name: 'MyApp',
      setup() {
        const message = ref('Hello Vue.js!')
        return { message }
      }
    })

    // 存到 window 上，方便在控制台里玩
    window.vm = app.mount('#root')
  </script>
</body>
</html>
✓ 为什么 <script> 放在 <body> 末尾

mount('#root') 执行时，页面上必须已经有 #root 元素。脚本放在末尾，浏览器先解析完 HTML 再执行它，就不会找不到元素。

小结

  • Vue 是渐进式框架：一个 <script> 就能用，也能一路扩展到大型应用。
  • 它的核心思想是数据驱动视图：你改数据，Vue 负责更新 DOM。
  • Vue 3 用 createApp(根组件).mount('#选择器') 创建应用，取代了 Vue 2 的 new Vue({ el })。
  • ref() 创建响应式值，JS 里读写用 .value，模板里直接用名字。
  • 模板中 {{ 表达式 }} 显示文本，v-model 把表单元素和数据双向绑定。
  • 原书的 Vue 2 生态已全面换代：Vite、Pinia、Vue Router 4、Vitest、Nuxt……后续章节逐一介绍。

动手练习

  1. 在同一个页面里创建两个独立的 Vue 应用，分别挂载到 #a 和 #b，确认修改一个不会影响另一个。
  2. 在插值里显示 message 的大写形式和长度，例如 HELLO (5)。
  3. 把本章的例子改写成选项式 API（data() 返回对象），确认效果一样。
  4. 故意在 setup() 里写一个普通变量 let count = 0 并在模板中显示，再在控制台修改 vm.count，观察页面为什么不更新；然后把它改成 ref(0)。
