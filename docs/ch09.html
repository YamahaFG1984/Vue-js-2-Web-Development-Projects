迁移一个老项目

如果你手上有一个真实的 Vue 2 项目要升级，大致路线如下：

ⓘ 迁移构建（@vue/compat）

Vue 官方提供了一个“兼容模式”的构建版本 @vue/compat：它的行为默认和 Vue 2 一致，同时对每一处用到已变更 API 的地方给出运行时警告， 可以逐项开关兼容特性。它让大型项目可以先跑起来、再一点点修。详见官方的 Vue 3 迁移指南。

⚠ 最大的拦路虎通常是第三方库

Vue 本身的迁移工作量往往不大，真正花时间的是 UI 组件库和各种插件：Element UI → Element Plus、Vuetify 2 → 3、BootstrapVue → BootstrapVueNext 等， 它们的 API 可能有不小的变化。先确认每个依赖都有可用的 Vue 3 版本或替代品，再开始迁移。
