Vue 3 项目实战：用 6 个应用学会现代 Vue

这套教程改编自 Packt 出版的《Vue.js 2 Web Development Projects》（Guillaume Chau 著）。 原书“边做项目边学”的结构被完整保留 —— Markdown 笔记本、卡牌游戏、客服中心、地图博客、在线商店、实时仪表盘 —— 但书中的 Vue 2 代码全部改写为 Vue 3，2017 年的工具链也全部换成了今天的生态。 每一处改动都配有“原书写法 / 现在写法”的对照，并配有大量示意图。

为什么要“翻新”这本书

原书写于 2017 年，结构清晰、项目有趣，至今仍是很好的入门路线。但它基于 Vue 2，而 Vue 2 已于 2023 年底停止维护； 书中用到的 vue-cli、Vuex、Jest 配置、vue-googlemaps、Google+ API 等，要么已被官方替换，要么已经无法使用。照着原书敲代码，今天会处处碰壁。

六个项目，一条渐进的路线

Vue 自称“渐进式框架”，这本书的结构也是渐进的：前三章只需要一个 HTML 文件和一个 <script> 标签； 从第 4 章开始引入构建工具，然后一层层加上路由、状态管理、测试、国际化、服务端渲染，最后是一个全栈实时应用。

这套教程写给谁

  • 会一点 HTML / CSS / JavaScript，想学一个前端框架的人。每个概念都从“为什么需要它”讲起，配图解释原理。
  • 手里有 Vue 2 书籍或老项目的人。每一处改动都有“原书 Vue 2 / 现在 Vue 3”的左右对照，附录还有一份完整的速查表。
  • 想系统了解 Vue 3 生态的人。路由、状态管理、测试、国际化、SSR、全栈实时，覆盖了一个真实项目会遇到的大部分环节。
ⓘ 需要什么前置知识

会用变量、函数、数组、对象就够了。箭头函数、解构、模板字符串、async/await、ES 模块会在用到时简单说明。 从第 4 章起需要用命令行运行 npm 命令。

版本说明

本教程基于 Vue 3.5+、Vite、Vue Router 4、Pinia 3、Vitest、vue-i18n 11、Nuxt 4、Meteor 3 编写。 前端生态更新很快，命令行提示、配置文件的细节可能和你看到的略有不同，遇到差异时以各工具的官方文档为准； 本教程讲解的核心概念（响应式、组件、路由、状态管理、测试、SSR）是稳定的。

✓ 本地预览这套页面

所有页面都是纯静态 HTML，直接双击 docs/index.html 就能打开；也可以在仓库根目录运行 npx serve docs。 部署到 GitHub Pages：在仓库 Settings → Pages 中选择从 master 分支的 /docs 目录发布即可。
