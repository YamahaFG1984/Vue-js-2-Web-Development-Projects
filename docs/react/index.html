React 项目实战：用 6 个应用学会现代 React

这套教程以 Packt 出版的《Vue.js 2 Web Development Projects》（Guillaume Chau 著）的六个项目为蓝本 —— Markdown 笔记本、卡牌游戏、客服中心、地图博客、在线商店、实时仪表盘 —— 用 React 19 和它最新的生态重新实现了一遍。每个概念都从“为什么需要它”讲起，并配有大量示意图和在线演示。

为什么用这六个项目学 React

原书的项目设计得很好：每个项目都是一个完整、有趣的应用，难度逐级上升，新概念总是在“恰好需要它”的时候出现。 这些项目要解决的问题 —— 组件化、表单、路由、登录、全局状态、地图、测试、国际化、服务端渲染、实时数据 —— 和框架无关， 所以非常适合拿来学习 React 和它的生态。

补充内容与进阶专题

原书的六个项目覆盖了主线，但今天的 React 开发还有一些“标配”值得掌握。我们没有把它们堆在书的末尾，而是放进最适合的项目里， 让你在真实场景中学会它们。这些小节都带有 补充 标记：

章节补充的内容
第 2 章 · 笔记本状态快照与更新函数、过期闭包、Strict Mode、useRef 与 ref 回调
第 3 章 · 卡牌游戏createPortal、state 与 dispatch 分开的 Context
第 4 章 · 工程化按功能组织与路径别名、TypeScript、环境变量与构建模式
第 5 章 · 客服中心（拆为上下两篇）useClickOutside 与 useEffectEvent、Session 与 JWT、<Activity>、Zod + React Hook Form、复合组件、错误边界
第 6 章 · 地图博客Zustand persist 中间件、useSyncExternalStore 与原生 <dialog>、大量数据时的渲染性能
第 7 章 · 在线商店Playwright E2E 与 MSW、Next.js Server Actions 与混合渲染、GitHub Actions、Docker、Sentry
第 8 章 · 实时仪表盘大列表性能（memo、虚拟滚动）、完整的 Express + SSE 实时方案

这套教程写给谁

  • 会一点 HTML / CSS / JavaScript，想学 React 的人。第 1–2 章不需要安装任何东西，打开浏览器就能跟着做。
  • 学过 Vue、想上手 React 的人。同样的项目、同样的结构，可以和本站 Vue 版逐章对照；附录有一份完整的对照表。
  • 只看过老教程（class 组件、Create React App、Redux 样板代码）的人。这里全部是 2026 年的写法。
  • 已经会写 React、想再进一步的人。第四部分的进阶专题讲原理、架构、跨端和 AI 应用，可以单独阅读。
ⓘ 需要什么前置知识

会用变量、函数、数组、对象就够了。箭头函数、解构、展开运算符、模板字符串、async/await、ES 模块会在用到时说明。 从第 3 章起需要安装 Node.js 并使用命令行。
