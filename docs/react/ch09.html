Vue ↔ React 对照

本站同一套六个项目分别用 Vue 3 和 React 19 实现了一遍。这份对照表把两个框架里“做同一件事”的写法放在一起， 适合学过其中一个、想快速上手另一个的读者，也可以帮你理解两者设计思路的根本差异。

最根本的差异：更新模型

这一个差异，解释了后面几乎所有写法上的不同：

  • Vue 的数据可以直接修改（notes.value.push(x)），React 必须创建新值（setNotes([...notes, x])）。
  • Vue 的 setup() 只执行一次，React 的组件函数每次渲染都执行 —— 所以 React 需要 Hooks 规则、依赖数组、useRef。
  • Vue 的 computed 自动知道依赖；React 的 useMemo / useEffect 要手写依赖数组（交给 ESLint 检查）。

Vue 3

const notes = ref([])
</script>

<template>
  <ul v-if="notes.length">
    <li v-for="n in notes" :key="n.id"
        :class="{ fav: n.favorite }">
      {{ n.title }}

  </ul>

React 19
import { useState } from 'react'

export default function Notes() {
  const [notes, setNotes] = useState([])
  return notes.length > 0 && (
    <ul>
      {notes.map((n) => (
        <li key={n.id} className={n.favorite ? 'fav' : ''}>
          {n.title}
        </li>
      ))}
    </ul>
  )
}

开发时的检查—StrictMode：渲染两次、effect 挂载两次
ⓘ 思路不同

Vue 问“在哪个时刻做什么”，React 的 effect 问“这个副作用要和哪些数据保持同步”。把 effect 理解成“同步”而不是“生命周期”，能少写很多 bug。

Vue 的长处

上手平缓、模板接近 HTML、响应式自动追踪几乎不用操心性能；官方提供路由、状态管理、构建工具，选择少、文档统一。

💙

React 的长处

“就是 JavaScript”，灵活度高；生态和就业市场最大；服务端组件、React Native 等方向走得最远。

🤝

共同点

组件化、单向数据流、虚拟 DOM、Vite、TypeScript、Vitest……学会一个，另一个的大部分概念都能迁移。

两个框架都非常成熟，没有错误的选择。最好的办法是：先把一个学扎实，再用对照的方式快速掌握另一个 —— 这正是本站把同样的项目做两遍的目的。
